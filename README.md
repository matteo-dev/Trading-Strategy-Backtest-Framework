# Trading-Strategy-Backtest-Framework
outil complet développé en Python pour l'analyse financière quantitative. Il permet de télécharger des données historiques via YFinance, de convertir les devises, d'analyser performance/risques d'un univers diversifié d'actifs, d'implémenter des stratégies avec des indicateurs techniques et d'évaluer rigoureusement cela via un moteur de backtest.
